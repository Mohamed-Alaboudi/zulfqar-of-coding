# Extract a procedure into a skill

Apply this skill only when explicitly invoked as `$extract`.

Find a recurring procedure in the current project's durable memory or equivalent project records. If the invocation names a topic, scope the review to it; otherwise inspect the relevant index and recent records.

Require evidence that the procedure recurred at least twice, is reusable beyond a one-off repository quirk, and is not already covered by an existing skill. Stable facts belong in project memory, not a new procedure skill.

Create an extraction brief with the supporting records, a kebab-case name, positive triggers, anti-triggers, and the generalized ordered procedure. Show the brief first if non-obvious judgment was required to generalize it.

Use the available skill-authoring workflow to create and test the skill rather than hand-authoring an unvalidated result. Verify its trigger test actually ran and passed. Report the new skill's path, name, routing description, and supporting records. If it supersedes a memory note, ask whether to retain that note as history; never delete it automatically.

If the recurrence or non-duplication bar is not met, say so plainly. Prefer extending an existing skill over creating an overlapping trigger.
