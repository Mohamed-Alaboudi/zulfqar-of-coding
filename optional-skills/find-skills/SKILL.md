# Find skills

Use this skill when a user asks how to perform a common task, asks whether a skill exists, wants to find a skill, tool, template, or workflow, or expresses interest in extending agent capabilities. Do not use it for a request that is already clearly covered by an available skill or can be completed directly without discovery.

First identify the domain, the concrete task, and the capability the user wants. Search the approved skill-discovery surface using specific, task-focused terms. Prefer established sources and inspect a candidate's provenance, maintenance signals, installation count or adoption evidence when available, and its stated behavior before recommending it.

Present a short set of relevant candidates with what each does, evidence of quality, a safe installation method, and a link or reference for further review. Do not recommend a result solely because it appears in search output.

Install only after the user explicitly asks. If no suitable skill is found, say so and offer to help directly; suggest authoring a new skill only when the need is likely to recur.
